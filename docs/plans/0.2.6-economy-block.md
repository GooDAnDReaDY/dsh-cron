## Границы и инварианты

- Один блок → одна ветка `feat/0.2.6-economy-block` → один PR → один релиз 0.2.6.
- Новых зависимостей блок не добавляет; вызовы модели идут через сервис харнесса.
- **Все обращения к модели fail-open:** ошибка, таймаут или невалидный ответ LLM
  не приводят к потере отчёта, зависанию запуска или ложной тишине.
- Секреты — только credential-ссылки. Ключи и токены в рецептах и промптах не
  хранятся.
- Публичные экспорты `lib/index.js` не ломаются; поведение существующих
  маршрутов не меняется.
- Рефакторинг (#97) идёт первым коммитом блока: новые фичи ложатся в уже
  разобранную структуру, а не наоборот.
- `lib/client.js` остаётся single-file (требование загрузчика DSH).

## План проверки блока

- `npm test` до и после каждого пункта; базовый результат на старте — 128/128.
- Новые тесты: каскад моделей с подставным исполнителем, вердикты правила тишины
  (тихо/громко/ошибка/невалидный JSON), разбор диагноза инспектора, инструменты
  подстройки, валидность всех рецептов и отсутствие деструктивных команд.
- `bash deploy.sh check` (тесты + гейт размера + кандидат).
- Приёмка на изолированном MiniPC: установка кандидата, проверка новых полей и
  инструментов через API, отображение в браузере.
- Независимое ревью PR перед merge.
