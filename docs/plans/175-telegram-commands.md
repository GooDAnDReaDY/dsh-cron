# План реализации: Интерактивные команды Telegram-бота (#175)

## Контекст и цель
Telegram-интеграция в dsh-cron сейчас поддерживает только односторонние отчёты и инлайн-кнопки под ними.
Цель: добавить поддержку текстовых команд Telegram-бота (/status, /tasks, /run, /pause, /resume, /log, /help).

## Поддерживаемые команды
1. `/status` — сводка: даемон, число задач (активных / на паузе), запущенные в текущий момент, суточные затраты USD и токенов (через `calculateRollingCost`).
2. `/tasks` — список задач с текущим состоянием, ID и расписанием.
3. `/run <id>` — немедленный запуск задачи.
4. `/pause <id>` — приостановка задачи с сохранением `pausedReason`.
5. `/resume <id>` — возобновление задачи.
6. `/log <id>` — вывод последнего запуска (статус, длительность, вывод/ошибка).
7. `/help` / `/start` — список доступных команд.

## Безопасность
Авторизация по `allowedChatId` (из настроек dsh-cron или DSH gateway). Неавторизованные запросы отклоняются с кодом 403 / предупреждением.
