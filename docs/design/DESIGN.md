# DESIGN.md — dsh-cron

## Product / Purpose
- Назначение: Интегрированный планировщик cron-задач и фоновой автоматизации для DeepSeek Harness. Позволяет запускать агентские сессии по расписанию, выполнять автоматические проверки и предоставлять визуальный интерфейс управления задачами.
- Аудитория: Пользователи и операторы DeepSeek Harness, автоматизирующие периодические процессы (утренние сводки, проверка тикетов, мониторинг серверов).
- Статус: In Development, v0.1.0, публичный npm-пакет @goodandready/dsh-cron.

## User Surfaces
- Web/UI: 
  - Экран «Запланированные задачи» (полноэкранный оверлей в центральной колонке интерфейса DSH, аналогично dsh-kanban через mountOverlay/mountBoard).
  - Кнопка вызова в боковой панели (sidebar-entry) рядом с новой сессией и канбаном.
  - Кнопка «Создать ⌄» в правом верхнем углу с дропдауном:
    - 💬 «Создать с DSH» (запуск интерактивного диалога постановки задачи агенту).
    - ✏️ «Настроить вручную» (модальное окно с формой параметров расписания, промпта, типа запуска).
  - Табы фильтрации: «Все», «Активные», «Приостановленные», «Завершено».
  - Поисковая строка: «Поиск запланированных задач».
  - Карточки задач: статус-иконка (play/pause/done), название, расписание (человекочитаемое + raw cron), контекстные действия (пауза/старт, запуск сейчас, редактировать, удалить, логи).
  - Блок «Рекомендации»: готовые шаблоны (Ежедневная сводка, Еженедельный обзор, Мониторинг) в один клик.
  - Карточка настроек в слоте settings.plugin.item (namespace dsh-cron).
- Chat / Slash Commands:
  - Команда /cron для быстрого создания или просмотра статуса запланированных задач прямо в чате.
  - LLM Tools: cron_schedule_task, cron_list_tasks, cron_toggle_task, cron_get_history.
- API: HTTP эндпоинты /dsh-cron/* (tasks, toggle, run-now, history, templates).

## Visual Direction
- Атмосфера: Строгий утилитарный темный/светлый интерфейс в нативном стиле DeepSeek Harness (дизайн как на утвержденных скриншотах пользователя).
- Использование нативных токенов темы DSH: --dsw-alias-bg-layer-*, --dsw-alias-border-l2, --dsw-alias-label-primary, --dsw-alias-label-secondary.
- Иерархия: читаемые карточки с четким акцентом на статусе и времени следующего запуска.

## Foundations
- Семантические цвета статусов:
  - Зеленый/активный: рабочее расписание.
  - Серый/приостановленный: на паузе.
  - Синий/информационный: шаблоны и рекомендации.
  - Красный: ошибка выполнения последнего запуска.
- Доступность: aria-label для всех иконок, управление клавиатурой в модальных окнах, семантические формы.

## Components And States
- Components:
  - CronSidebarButton: кнопка в левом сайдбаре DSH.
  - CronScreen: основной оверлей со списком, табами и рекомендациями.
  - CreateDropdown: всплывающее меню выбора способа создания.
  - ManualTaskModal: модальная форма создания/редактирования.
  - TaskItem: строка задачи с переключателем состояния и меню действий.
  - RecommendationCard: плашка с готовым шаблоном.
  - CronSettingsCard: карточка параметров плагина в настройках.
- States:
  - Loading: скелетон списка при загрузке.
  - Empty: дружелюбный пустой экран с предложением создать первую задачу или выбрать из рекомендаций.
  - Error: баннер с ошибкой и кнопкой повтора.

## User Flows
1. Создание через DSH-чат: пользователь пишет «напоминай каждый день в 9 утра...» -> агент вызывает тул cron_schedule_task -> задача сохраняется и появляется на экране.
2. Создание через команду: пользователь вводит /cron add 0 9 * * 1-5 <промпт>.
3. Создание вручную: клик по кнопке сайдбара -> клик «Создать ⌄» -> «Настроить вручную» -> заполнение формы -> сохранение.
4. Выполнение по крону: срабатывает таймер croner -> запуск сессии агента или команды -> запись в историю -> доставка результата.
