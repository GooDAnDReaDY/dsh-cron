# @goodandready/dsh-cron

Плагин планировщика и фоновой автоматизации для DeepSeek Harness. Позволяет запускать агентские сессии и автоматические сценарии по расписанию через cron-выражения или интервалы, а также управлять ими через графический оверлей, команду `/cron` и инструмент вызова для модели (Tool Calling).

## Возможности

- **Визуальный интерфейс «Запланированные задачи»**:
  - Открытие из бокового меню DSH (кнопка рядом с канбаном).
  - Полноэкранный оверлей со списком активных и приостановленных задач.
  - Поиск и фильтрация по табам: «Все», «Активные», «Приостановленные», «Завершено».
  - Выпадающее меню «Создать ⌄»:
    - 💬 **Создать с DSH** (интерактивная постановка задачи агенту в чате).
    - ✏️ **Настроить вручную** (модальное окно с выбором параметров расписания, промпта и режима).
  - Готовые рекомендации в 1 клик («Ежедневная сводка», «Еженедельный обзор», «Мониторинг дальнейших действий»).
  - Быстрые действия: запуск немедленно («Запустить сейчас»), пауза/возобновление, удаление.
- **Команда `/cron` в чате**:
  - `/cron list` — вывод списка активных задач.
  - `/cron add "<расписание>" <промпт>` — быстрое создание задачи.
  - `/cron pause <id>` / `/cron resume <id>` — пауза и возобновление.
  - `/cron run <id>` — немедленный запуск.
- **Инструменты модели (AI Tool Calling)**:
  - `cron_schedule_task` — агент может сам запланировать задачу в ходе диалога.
  - `cron_list_tasks` — просмотр задач.
  - `cron_toggle_task` — управление жизненным циклом.
- **Движок планировщика**:
  - Построен на базе `croner` с поддержкой выражений стандартного cron (`0 9 * * 1-5`) и интервалов (`every 15m`, `daily`, `weekdays`).
  - Персистентное хранение состояния в JSON с атомарной записью.
  - Журналирование запусков и сохранение истории выполнения (длительность, статус, вывод).

## Установка

```bash
dsh plugin --profile web add @goodandready/dsh-cron@0.1.0
```
